# crustf

Pure Rust JVM class file emitter with a fluent, assembler-style builder API.

`crustf` lets you produce `.class` files straight from Rust code without
shelling out to `javac`. It is `no_std` friendly (depends only on `alloc`)
and builds for `wasm32-unknown-unknown` / `wasm32-wasip1`, so it is equally
happy inside a Wasm tool-chain or on a microcontroller target that ships
`alloc`.

```rust
use crustf::{AccessFlags, ClassFileBuilder, MethodBuilder};

let bytes = ClassFileBuilder::new("TestHello")
    .method(
        MethodBuilder::new("<init>", "()V")
            .access_flags(AccessFlags::PUBLIC)
            .code(|c| {
                c.aload(0)
                 .invokespecial("java/lang/Object", "<init>", "()V")
                 .return_void();
            }),
    )
    .method(
        MethodBuilder::new("main", "([Ljava/lang/String;)V")
            .access_flags(AccessFlags::PUBLIC | AccessFlags::STATIC)
            .code(|code| {
                code.getstatic("java/lang/System", "out", "Ljava/io/PrintStream;")
                    .ldc_string("Hello from assemb!")
                    .invokevirtual("java/io/PrintStream", "println", "(Ljava/lang/String;)V")
                    .return_void();
            }),
    )
    .build()?;

std::fs::write("TestHello.class", &bytes)?;
# Ok::<_, crustf::Error>(())
```

```
$ java TestHello
Hello from assemb!
```

## Workspace layout

```
crustf/
├── crates/
│   ├── crustf-spec/          pure data model + binary encoder  (JVMS §4)
│   ├── crustf-asm/           fluent builder layer with label & pool resolution
│   ├── crustf-jar-builder/   JAR / ZIP writer, no_std + alloc, WASM safe
│   └── crustf/               umbrella re-exports for crate consumers
└── tests/jvm-integration/    end-to-end tests that run `java` on generated bytes
```

Each crate is documented with `cargo doc --open`. The dependency direction
is strictly `crustf-spec → crustf-asm → crustf`, so you can depend on just
the lower layer if you do not need the builder.

### `crustf-spec`

* Exhaustive data model of every `ClassFile`, `ConstantPool`, attribute,
  field, method and bytecode instruction defined by JVMS (Java SE 25).
* Binary encoder that writes bytes in JVMS-order.
* Modified-UTF-8 codec with ASCII fast path and surrogate-pair support.
* All 200+ opcodes (plus reserved `breakpoint`, `impdep1`, `impdep2`) and
  every `wide`-modified variant are modelled as enum variants.
* `#![no_std]` when the `std` feature is disabled.

### `crustf-jar-builder`

* `JarBuilder`, `Manifest`, and a low-level `ZipWriter`.
* Writes STORED (method 0) ZIP 2.0 archives — the subset `java -jar`,
  `JarFile`, and `JarInputStream` require.
* Inline CRC-32 (`IEEE 802.3` / PKZIP polynomial, table built in `const fn`).
* Zero dependencies beyond `alloc`; safe to cross-compile to
  `wasm32-unknown-unknown` or `wasm32-wasip1`.
* `Manifest` folds lines at the 72-byte boundary mandated by the JAR spec
  and converts `Main-Class` slashes to dots automatically.

```rust
use crustf::{AccessFlags, ClassFileBuilder, JarBuilder, MethodBuilder};

let class_bytes = ClassFileBuilder::new("HelloJar")
    .method(MethodBuilder::new("<init>", "()V")
        .access_flags(AccessFlags::PUBLIC)
        .code(|c| { c.aload(0).invokespecial("java/lang/Object", "<init>", "()V").return_void(); }))
    .method(MethodBuilder::new("main", "([Ljava/lang/String;)V")
        .access_flags(AccessFlags::PUBLIC | AccessFlags::STATIC)
        .code(|c| {
            c.getstatic("java/lang/System", "out", "Ljava/io/PrintStream;")
             .ldc_string("hi from the jar")
             .invokevirtual("java/io/PrintStream", "println", "(Ljava/lang/String;)V")
             .return_void();
        }))
    .build()?;

let jar_bytes = JarBuilder::new()
    .main_class("HelloJar")
    .file("HelloJar.class", class_bytes)
    .build()?;

std::fs::write("hello.jar", &jar_bytes)?;
// $ java -jar hello.jar
// hi from the jar
# Ok::<_, crustf::Error>(())
```

### `crustf-asm`

* `ClassFileBuilder`, `FieldBuilder`, `MethodBuilder`, `CodeBuilder`.
* Unified [`AccessFlags`][af] bag covers class / field / method / parameter
  contexts and truncates to the correct JVMS flag set on the way down.
* Labels, `tableswitch` / `lookupswitch`, short / wide branches resolved
  automatically during `.build()`.
* Auto-narrowing: `iload(0)` emits `iload_0`, `iload(5)` emits `iload 5`,
  `iload(500)` emits `wide iload 500`. Same for stores and `iinc`.
* Auto `ldc` vs `ldc_w` vs `ldc2_w` selection based on the resolved
  constant pool index.
* `max_locals` is inferred from parameter slots plus the widest local
  index actually used.

[af]: crates/crustf-asm/src/access.rs

## Class file version defaults

`ClassFileBuilder::new(...)` defaults to major version `49` (Java SE 5).
Class files in major ≤ 49 are verified with the legacy type-inference
verifier, which does not require a `StackMapTable` attribute — so simple
builds with back branches stay correct without extra wiring. Upgrade
explicitly with `.version(JAVA_17)` when you need modern features
(`invokedynamic`, dynamic constants, sealed classes, …) but you will also
need to supply a correct `StackMapTable` in those cases.

## Testing

The `tests/jvm-integration` crate compiles class files with `crustf` and
drives a real `java` binary to compare stdout against expected output.
Each file in `tests/jvm-integration/tests/` exercises a different slice of
the instruction set:

| file | covers |
| --- | --- |
| `hello_world.rs` | `getstatic`, `ldc_string`, `invokevirtual` |
| `arithmetic.rs` | `i/l/f/d add/sub/mul/div/rem`, `ishl`, `iand`, `ior`, `ixor` |
| `control_flow.rs` | `if_icmp*`, `goto`, `iinc`, `tableswitch`, `lookupswitch` |
| `arrays.rs` | `newarray`, `anewarray`, `iaload`/`iastore`, `arraylength` |
| `references.rs` | `new`, `invokespecial`, `getfield`/`putfield`, `checkcast`, `instanceof`, `invokeinterface` |
| `constants.rs` | every `iconst_*`, `lconst_*`, `bipush`, `sipush`, `ldc`, `ldc_w`, `ldc2_w` |
| `conversions.rs` | `i2l`, `i2f`, `i2d`, `l2i`, `l2d`, `d2i`, `i2b`, `i2c`, `i2s` |
| `comparisons.rs` | `lcmp`, `ifnull`, `ifnonnull` |
| `stack_ops.rs` | `dup`, `swap`, `pop` |
| `exceptions.rs` | `athrow`, `exception_table` (try/catch) |
| `jar.rs` | `java -jar` of a packaged JAR, custom manifest attributes |

Run everything:

```bash
cargo test --workspace
```

Tests skip gracefully when `java` is not on `PATH`.

  `crustf-spec` and `crustf-asm`
